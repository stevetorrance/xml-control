Tutorial

The order to do things in, one small step at a time. Each chapter builds on the one before.

The built-in help is a reference: it tells you what every feature does. This tutorial is the other half: it shows you what to do first.

Chapters

  1. Chapter 1: Getting Started
    What SentinelSCADA is, how the server and the web client fit together, the three security modes, the three display modes, and where to find help.
  2. Chapter 2: Create a New Project
    Starting and stopping properly, creating a project, finding your way around the client, and a first working gauge fed by the Modbus Simulator.
  3. Chapter 3: Add Session Control
    The Session Panel widget for logging in and out and leaving Kiosk Mode, plus a first look at the security settings.
  4. Chapter 4: WorldSystem and Clocks
    Adding the WorldSystem driver, using a Clock widget as a real-time clock in any time zone or as a timer, and why the tag data type matters.
  5. Chapter 5: Project Properties
    The Project Properties tabs, UI themes, new screen defaults and startup mode, the Screen Swapper for unattended displays, and generating the project documentation PDF.
  6. Chapter 6: Screen Properties
    The settings for a single screen: canvas size, background colour and image, access level, and the alignment grid.
  7. Chapter 7: Add a Screen and Navigation
    Creating a second screen, adding Navigation Links so operators can move between screens, the arrow options, and who can see and use a link.
  8. Chapter 8: Process Graphics
    The built-in pump, valve, tank, pipe and shape objects, changing a pump's shape and orientation, and binding graphics and pipework to a tag so they change colour in Run Mode.
  9. Chapter 9: Symbol SVG
    Bringing in your own vector artwork with the Symbol SVG widget, Off and On files, colour modes, keeping artwork clean, and when to use the Image widget instead.
  10. Chapter 10: Add a Modbus Device
    Adding a real Modbus/TCP device, its Unit ID, poll rate, address offset and word order, creating a Coil and a Holding Register tag with limits, and operating them from a switch and a knob.
