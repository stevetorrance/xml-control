Widget Summary

Every widget in the Toolbox, with the same glyph you see on its button, and what it is for.

There are 28 widgets, in four groups that match the Toolbox in the designer. Most display widgets only show data. Widgets that write to tags (the Controls group, Recipe Control, the Data Label when Allow Control Write is on, and the pump, valve and symbol widgets when click-to-toggle is on) take effect on live equipment as soon as an operator uses them - subject to the authentication settings in place.

Process & Symbols

Equipment and drawing pieces for building a process picture (a P&ID-style screen).

Feed Pump

Built-in pump symbol, ready to drop on a screen with no file to upload. A Shape property swaps the artwork in place (pump, motor pump, centrifugal blower, box fan) without losing its tag binding, colours or size. It shows running or stopped from its bound tag, and can optionally write back to toggle that tag when clicked.

Control Valve

Built-in valve symbol with several shapes (gate valve, globe valve, butterfly damper, air damper). Shows open or closed from its bound tag so operators can see the state of the line at a glance, and can optionally toggle the tag on click.

Storage Tank

A built-in storage tank symbol for vessels, hoppers and reservoirs, with a level indicator built in, so the fill level follows its bound tag, between minimum and maximum scale values you set for empty and full. Low and high alert thresholds switch the fill to warning colours, so operators can see how full the tank is, and when it needs attention, at a glance. Use it as the anchor of a process picture, with pipes running in and out.

Line / Pipe

A straight, thick, coloured line used to represent pipework, or just as a divider or connector. It can run horizontally, vertically or diagonally, and its thickness is adjustable. Bind it to a tag and it changes colour with the tag: one colour for active (1) and another for inactive (0), on top of its default colour, so a run of Line / Pipe widgets shows at a glance which pipes are carrying flow on a P&ID-style screen.

Rectangle

A rectangle with adjustable corner radius, border and default fill. Bound to a tag, its fill switches between an active (1) and an inactive (0) colour, so it can double as a simple status block. Also handy for panels, equipment housings and coloured backing areas that organise a busy screen into zones.

Ellipse / Circle

An ellipse or circle with border and default fill. Bound to a tag, its fill switches between an active (1) and an inactive (0) colour, which makes it a ready-made indicator lamp. Also useful for round vessels, motor outlines and decorative shapes.

Polyline

An open multi-point line, so pipes can bend around corners. Drag the points to reshape it. Like the straight Line / Pipe, it takes an active (1) and an inactive (0) colour from its bound tag.

Polygon

A closed multi-point shape with border and fill, which switches between an active (1) and an inactive (0) colour from its bound tag. Use it for irregular vessels, hoppers, arrows, buildings or zone outlines that a rectangle or ellipse can't describe.

Symbol SVG

Places your own custom SVG artwork on the canvas and drives its on/off state from a tag. You can supply separate SVG files for the on and off states and the widget swaps between them, set an on colour and an off colour (for example green when running, grey when stopped), and add an optional glow effect to make an active item stand out. It is the only widget that accepts SVG content, and scripts and external references are stripped on import. Reach for it when the built-in shapes don't cover your equipment.

Image Widget

A static raster image (PNG, JPG, GIF or WEBP), with an optional second image shown when its bound tag is 1. Fit, corner radius and opacity options are available, plus an optional dimmed or greyscale look while the bound tag is inactive. Good for logos, photographs, site plans and backgrounds. It does not accept SVG: use Symbol SVG for vector artwork.

Display & Data

Widgets that show information. They read tags and do not write, with one exception: a Data Label can accept typed-in values when Allow Control Write is on.

Data Label

Shows the live value of a bound tag in a styled box with a title, pre-text and suffix (for example a unit such as °C or bar), a value format pattern to control the decimal places, and your choice of fonts and colours. It can also act as a quick entry field: with Allow Control Write on, an operator taps the value in Kiosk Mode to type in a new one on a numeric keypad. The workhorse of any screen.

Text Widget

Fixed text that never changes at run time: titles, headings, notes and captions. It has a transparent background option so labels can sit on top of symbols. For text that changes with a tag, use a Data Label or Text Lookup instead.

Gauge

A classic 270° analog dial for a single process variable. Three colour zones (for example green, amber and red) show whether the reading is healthy at a glance, and the face, needle and ticks can all be recoloured to suit your theme.

Clock

Two jobs in one. It can show the live time of day in any time zone, analogue or digital, or act as a process timer driven from a PLC, counting up or down like a stopwatch. A clock in each time zone is a quick way to show a multi-site operation.

Andon

A stack of two to five lights that each switch on when the bound tag meets a condition, like the tower light on a production line. It gives operators a plain red, amber or green status that can be read from across the room.

Ticker Tape

A horizontally scrolling text strip, either fixed text or fed from a string tag. Place it along the bottom of a screen for rolling status messages, shift notices or plant announcements.

Text Lookup

Turns a numeric tag value into readable text using a project-wide dictionary, so a state code of 3 reads as “Mixing” rather than a bare number. Entries can carry their own colour or blink, and one dictionary can serve many widgets.

Bar/Pie Chart

Compares several current tag values side by side, as bars or as pie segments. It is best for showing how things are split or ranked right now, such as tank levels or the load on each pump. It shows current values only, not history.

Trend Chart

A rolling live line plot of one or more tags against time, with colour-coded series and a legend. It makes it easy to see which way a process variable is heading. It plots a live buffer rather than the historian, so use a report for stored history.

Controls

Widgets that act. They write to tags, and so to live equipment, the moment an operator uses them. (Recipe Control, under Alarms & Recipes, does the same.)

Button / Switch

Writes a discrete on or off to a tag. It works as a momentary push button, a toggle, or a fixed Set On or Set Off, and its face lights to match the tag's current value. It disappears entirely for users who don't have write permission for the tag.

Analog Knob

A rotary control for a continuous setpoint, such as a speed or temperature target. Dragging moves the value smoothly without sudden jumps, and the value is written when the operator lets go. It greys out into a read-only display for users without write permission.

Analog Slider

A linear control for a continuous setpoint, horizontal or vertical, with snap steps and an optional live value label. Like the knob, it writes on release and becomes a read-only display for users without write permission.

Mode Selector

Chooses one of up to eight named positions, such as Hand / Off / Auto, Duty / Standby or Speed 1 / 2 / 3, each writing its own value to the bound tag. The lit position always follows the tag, with a dashed outline while a click waits to be confirmed, and each position can have its own colour. It can ask for confirmation before writing, and becomes a read-only display for users without write permission. Use a Button / Switch for plain on or off.

Navigation Link

A button that switches to another screen in Run Mode, the building block of any navigation bar. Each link has an arrow option and a visibility level, so operators can be kept out of restricted screens or shown the link greyed out.

Session Panel

Shows who is logged in, with an avatar and a role badge, and offers Log In, Log Out and Exit Kiosk buttons as the situation allows. Put one on a screen so operators can sign in without leaving the display.

Alarms & Recipes

Widgets for abnormal conditions and for loading sets of setpoints in one go.

Alarm Banner

A prominent strip showing the highest-priority active alarm and the alarm count, coloured by severity. It keeps an alarm visible whichever screen is showing, and clicking it opens the Alarm Summary.

Alarm Summary

A scrollable table of current and recent alarms. Operators with the right permission can acknowledge alarms in place, and in a 21 CFR Part 11 setup each acknowledgement goes into the audit trail.

Recipe Control

Lets an operator choose a recipe and send all of its setpoints to the equipment in a single write, so a product changeover is one action rather than a dozen. It works in two steps. Staging is read-only: the widget compares the proposed recipe values with the live process tags and shows each one with its deviation and a Matched or Mismatch status, turning a row green when it matches. That lets the operator wait for the plant to cool down or warm up from the previous batch before anything is written. Download then writes every value in one go, after a confirmation prompt and, where the tags or Part 11 mode require it, an electronic signature.
