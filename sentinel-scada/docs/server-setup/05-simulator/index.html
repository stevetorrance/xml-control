Part 5: Trying It with a Simulator

Goal See live data and a working write on your new server, with no real equipment, using a Modbus simulator.

Running the simulator

We used the headless build of ModbusHydra, started so it listens on this machine only. Where to put it and how to start it.

Watching a live value

Switching to Run Mode and seeing the value update, and the simulator’s request counter climbing.

Trying a write

A writable register, a value sent from Manual Control, and the simulator’s write counter going up.

Tidying up

Stopping the simulator and removing the test device when you have finished.
