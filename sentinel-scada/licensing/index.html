Evaluation mode

By default, SentinelSCADA runs in Evaluation mode if no licence key is installed. Evaluation mode is fully functional for development and testing, with the following limits:

  • Runtime limit — a cumulative 240 minutes of Run and Kiosk mode time per server session. Once it expires, connected clients exit Run Mode and return to Design Mode. Restarting the server resets the timer.
  • Tags — up to 64.
  • Drivers — up to 4 active device drivers.
  • Web clients — 1 concurrent connection.
  • History — 7 days maximum.
  • Reports — generated PDFs carry an Evaluation Mode watermark.
  • Security — Keycloak (CFR Part 11) integration is not available; XML and SQLite modes only.

Licensed editions

A valid licence key removes the session runtime restriction and unlocks operational capacity according to the edition.

Home Edition

For personal use, hobbyist projects and education.

  • Up to 512 tags, 8 active device drivers and 4 concurrent web clients.
  • 30 days of history.
  • Standard PDF reports, with no watermark.
  • XML and SQLite security modes.

Professional Edition

The baseline tier for single machines and standard utility facilities. A solid step up from Home for growing deployments.

  • Up to 4,096 tags, 64 active device drivers and 16 concurrent web clients.
  • Unlimited history.
  • Standard PDF reports, with no watermark.
  • XML and SQLite security modes. Keycloak support begins at Clipper.

Clipper Edition

The high-performance tier, for large process lines and multi-system integration.

  • Up to 16,384 tags, 128 active device drivers and 64 concurrent web clients.
  • Unlimited history.
  • Standard PDF reports, with no watermark.
  • All security modes: XML, SQLite and Keycloak (CFR Part 11).

TradeWinds Edition

The enterprise tier, for large facilities and plant-wide control architectures.

  • Unlimited tags, constrained only by the host hardware. Up to 240 active device drivers and unlimited concurrent web clients.
  • Unlimited history.
  • Standard PDF reports, with no watermark.
  • All security modes: XML, SQLite and Keycloak (CFR Part 11).

A licence is hardware-locked to the host system. For licence transfers or requests, contact XML Control — Software & Automation.
