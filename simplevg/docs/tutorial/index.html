Tutorial

The order to do things in, one small step at a time. Each chapter builds on the one before.

The built-in help (press F1 in SimpleVG) is a reference: it tells you what every feature does. This tutorial is the other half: it shows you what to do first.

Chapters

  1. Chapter 1: Getting Started
    What SimpleVG is, starting it, a tour of the workspace, switching between Light and Dark mode, and where to find help.
  2. Chapter 2: Your First Shapes
    Drawing a rectangle and an ellipse, positioning them with the Inspector, changing a fill colour with the SCADA swatches, and adding a text label.
  3. Chapter 3: Canvas, Grid and Snapping
    The Grid, Snap and Ruler buttons, canvas size and grid size on the Canvas tab, default styles for new shapes, zoom, and keyboard nudging.
  4. Chapter 4: SCADA Symbol Libraries
    Dropping ready-made symbols onto the canvas, ungrouping and restyling them, and ISA-101 Gray mode.
  5. Chapter 5: Saving and Exporting
    Saving SVG with full, cropped or selected-only bounds, exporting PNG at up to 4× resolution, Open versus Import, and the live SVG code drawer.
  6. Chapter 6: Lines and Curves
    The Line, Polyline and Bézier tools, stroke width and dashes, arrowhead markers, and editing curve nodes and handles.
  7. Chapter 7: Fills and Gradients
    Solid, linear and radial fills, the steel, copper and LED presets, and the SCADA colour picker.
  8. Chapter 8: Arranging Shapes
    Layer order, alignment, flip and mirror, rotation and the pivot marker, and circular patterns with Radial Array.
  9. Chapter 9: Tracing an Image
    Loading a sketch or scan onto the reference layer, setting opacity, scale and offset, and tracing it into clean vector shapes.
  10. Chapter 10: SCADA Tagging
    Setting an ID, classes and a data-tag on a shape for systems that read them (SentinelSCADA does not), the quick class chips, and seeing the result in the live SVG code.
  11. Chapter 11: The Live SVG Code Drawer
    An advanced chapter: reading the SVG that SimpleVG writes, editing it and watching the canvas follow, Find Selected, and Clean & Format XML.
