SimpleVG

To complement SentinelSCADA, a browser based Vector Graphics design tool with all the features you need for SCADA type graphics, and none of the complexity you don't.

What it is

SimpleVG is a lightweight vector graphics editor that runs in your browser, built for drawing SCADA and HMI diagrams. It reads and writes plain SVG files, so what you draw is ready to use elsewhere.

Features

  • Drawing tools — rectangles, circles, polylines, polygons, stars, arrows, arcs, Bézier pen, freehand paths and text.
  • SCADA symbol libraries — eleven ready-made sets covering pipes, valves, vessels, motors and pumps, sensors, meters and gauges, knobs and switches, lamps, HVAC ductwork, facilities and landscape. Drop them on the canvas, ungroup them, restyle them, or use them as inspiration.
  • ISA-101 Gray mode — one click gives new shapes the muted gray palette recommended for process HMIs.
  • Live SVG code drawer — edit the XML and the canvas follows, or draw and watch the XML update.
  • Trace Image layer — place a sketch or blueprint behind your work and trace it into clean vector paths.
  • Precision — grid snapping, rulers, alignment and pixel-accurate keyboard nudging.
  • Export — save SVG (full canvas, tight crop or selected shapes only) or high-resolution PNG.
