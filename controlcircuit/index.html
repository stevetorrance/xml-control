Evaluating

Try it before you buy

Install it and start drawing. With no licence entered, ControlCircuit runs as an evaluation: the full drawing tool, with the limits set out on the pricing page.

Licensed

Already bought a licence?

Download the same installer. Your licence is activated in the application, from Help > License Control, and that is what unlocks your tier.

Updates

Keeping up to date

Within your version, updates are free: install the new build over the old one. Help > Check for Updates tells you when there is one. It checks only when you ask, and sends nothing about you or your licence.

Requirements

What it runs on

Windows, with .NET Framework 4.8, which is included in Windows 10 and 11.
