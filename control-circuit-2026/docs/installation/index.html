Installation

Goal Install Control Circuit, accept the licence agreement, and reach the start screen. About five minutes, and there is nothing else to install first.

Control Circuit installs like any other Windows program: one setup file, a short wizard, and a desktop shortcut. The screenshots below were taken in a fresh Windows 11 virtual machine, and the steps are identical on a real PC.

Before you start

  • Windows 10 (version 1903 or later) or Windows 11. Control Circuit needs the .NET Framework 4.8, which both already include, so there are no extra downloads.
  • About 6 MB of disk space. The setup file is about the same size.
  • Administrator rights. The program installs under Program Files, so Windows will ask for permission once.

Installing

  1. Put the setup file somewhere local

    Copy the setup file to your Desktop (or any folder on your own drive) before you run it. The file name carries the version, so it will look like ControlCircuit2026v1.0.272.1313.exe.

    Tip Windows is happiest running an installer from a local drive. If the file is on a network share, a USB stick, or a shared folder from a virtual machine, copy it across first.

  2. Allow it to make changes

    Windows asks whether you want to allow the app to make changes to your device. Choose Yes.

    It may name the publisher as Unknown. That is expected for now: the setup file is not yet digitally signed, which is a separate step from being safe to run.

    Careful The Yes button is not the highlighted one: Windows highlights No by default. Check which you are clicking.

  3. Welcome

    The setup wizard opens on a short welcome page that shows the version you are about to install, who publishes it, and its size. The steps are listed down the left. Choose Next.

    Only ever this installer XML Control programs are distributed only through the Haggis Installer, which is itself an XML Control in-house utility, so every XML Control setup looks like the one below. If you ever meet an XML Control program in any other kind of installer, reject it as unsafe and do not run it.
    Why “Haggis”? Because a haggis is stuffed full of good things, and so is our installer: your program, its symbol libraries and everything it needs, packed snugly into one neat parcel. And, like the real thing, it was made in Scotland. We promise that ours is a good deal easier to swallow, and there is no need to address it with a poem.

  4. Read and accept the licence agreement

    Read the End User Licence Agreement, tick I accept the terms of the license agreement, then choose Next. You cannot install without accepting.

  5. Choose where it goes

    The default location is C:\Program Files (x86)\ControlCircuit2026, and for nearly everybody that is the right answer. The page also shows the space required and the space available on that drive.

    Create desktop shortcut is ticked for you. Choose Install.

  6. Finish

    The install takes a few seconds. When it reports Installation complete, leave Launch application now ticked and choose Finish.

First run

  1. Sign the licence agreement

    The first time Control Circuit starts, it shows the licence agreement again, this time for you to sign. Scroll to the end; a green Thank you for reading the agreement appears once you have. Type your initials (up to six characters) and choose I Accept.

    Your initials, the date and the software version are recorded with your acceptance. You are only asked once for each version.

  2. The start screen

    Control Circuit opens on its start screen. The Recent Projects list is empty because you have not made one yet. The version and build date are shown at the top, which is the first thing to quote if you ever need help.

    You are ready. Choose New to begin.

What you just did

  • Ran the setup file from a local drive and allowed it to install.
  • Accepted the licence agreement in the installer, then signed it on first run.
  • Reached the start screen with a desktop shortcut for next time.
